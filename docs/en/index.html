Product Features

What this multiplayer source focuses on

The project explains the player flow and code boundary: tables, rooms, protocols, client modules and club/tournament entry points.

Real-Time Table

Join, bet and settle

Room join/leave, online state, betting, folding, game start/end and settlement flows.

Social Play

Friends and private rooms

Create a private table, invite friends, apply to clubs and enter alliance or club-currency flows.

Multiplayer Match

MTT and SNG entry

Screens and match protocols show registration and tournament-table themes; rules require configuration review.

Live Gameplay

A complete real-time hand on one table

The table screen shows player seats, community cards, controls and live play. Source files cover betting, automated actions, end-game and player state paths.

Friends Room

A clear creation path for private games

The friends-room screen represents invitations and private tables, useful for evaluating friends rooms, member rooms and lightweight social play.

Tournament Entry

From registration to a multiplayer tournament table

MTT screens, ticket registration and match protocol files establish the tournament-entry theme; verify rules, settlement and admin scope before deployment.
