Product Scope

本项目的核心定位

本仓库重点是多人实时游戏工程：牌桌流程、房间生命周期、协议文件、Unity 客户端和 C++ 服务端。俱乐部、联盟与赛事是产品模块，但不与同账号的专项仓库重复竞争。

01 Table

实时牌局与房间

加入/离开、在线状态、下注、弃牌、开局、结束与结算组成多人牌桌主流程。

02 Social

好友局、俱乐部与联盟

创建私人房、邀请熟人、申请加入俱乐部、进入联盟和使用俱乐部币。

03 Match

MTT 与 SNG 入口

截图和赛事协议展示报名、牌桌与赛事相关流程，具体规则需按配置验收。

Live Gameplay

让玩家在同一张实时牌桌完成完整回合

牌桌截图展示多人座位、公共牌、操作区和实时对局入口。源码侧对应下注、自动操作、牌局结束和玩家状态相关文件。

Friends Room

面向熟人和私人局的创建路径

好友局页面强调邀请和私密牌桌场景，适合评估朋友房、俱乐部成员房与轻量社交玩法的产品流程。

Tournament Entry

赛事入口与多人牌桌结合

MTT 页面、报名票据和赛事协议文件形成赛事入口主题；部署前需确认完整赛制、结算与后台范围。

Engineering Structure

从 Unity 客户端到 C++ 游戏服务

代码目录提供客户端脚本、协议定义、房间逻辑、路由、订单、推送和运营接口，适合做二次开发评估。

Unity Client

GameApp、GameLoading、消息处理、Login 与 Assets。

Table Logic

allin、autobet、autofold、gameend 与玩家生命周期。

Protocol

Hall、Club、Friends、Match、Order、Push 等 proto/tars。

Services

Router、Order、Processor 与外部服务适配。

真实产品界面

图文模块覆盖大厅之外的创建、社交、运营和玩家视角。
